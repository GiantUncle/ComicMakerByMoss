# manga-craft — shared library

This directory is **not a skill**. It has no `SKILL.md`, so OpenCode does not
advertise it. It holds the craft and the tools every stage skill reads.

The stage skills reach it by relative path, for example
`../manga-craft/comic-planning.md`.
